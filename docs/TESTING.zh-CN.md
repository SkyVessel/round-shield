# Round Shield 测试版

版本：**1.0.1-test.1**。游戏：**Minecraft Java 26.1.2**。加载器：**NeoForge 26.1.2.94**。Java：**25**。

## 安装

从仓库 Releases 下载模组 JAR，放进对应游戏实例的 `mods` 文件夹。先移除旧版圆盾 JAR，避免重复加载。启动 Minecraft 即可，不需要 FORM。联机测试时服务端和客户端安装同一版本。

圆盾、装备格、轮盘和箭袋没有额外依赖。挂载提灯的动态光源需要另装适配 26.1.2 的 LambDynamicLights；光影、第一人称动画和第三人称动画模组由测试员另行选择，本 Release 不附带这些模组。

可在创造模式搜索 Round Shield / Quiver，或使用：

```text
/give @s round_shield_:round_shield
/give @s round_shield_:quiver
/give @s minecraft:lead
/give @s minecraft:lantern
```

## 使用

打开物品栏，把一根栓绳放进角色旁新增的格子，解锁五个装备格。关闭配方书后操作左侧装备区。按住鼠标侧键 Mouse 4，移向一格后松开即可取用，再次选择收起。按键可在 Controls → Inventory 更改。

箭袋只能放右背格。提灯可以放任何装备格，身体上的挂点始终是后腰。盾牌收起后不显示在背部或腰部，这是当前设计。滚轮/数字键恢复普通主手物品，副手保持。

箭袋装普通箭：拿箭点击箭袋，或拿箭袋点击箭。最多 320 支。手持箭袋右键会丢出最多 64 支箭；装备在右背时为弓弩供箭。

## 必要检查

1. 从快捷栏和轮盘分别取出圆盾，检查手持与举盾时贴合手臂，不浮空；左右主手设置都检查一次。
2. 提灯分别存放在不同装备格，检查后腰位置不变；取到手上时，不重复显示腰部提灯。
3. 后腰格放入剑或工具，检查该格不再被提灯专用规则占用。
4. 轮盘取出、收起、滚轮/数字键切换后，检查主副手独立，物品数量与耐久正确。
5. 保存退出再进入，检查装备与箭袋内容保留。
